# Yaqeen Advisory website

Open **START-HERE.html** (or docs/START-HERE.md) first. It explains every step to launch and edit the website.

Folder map (you only ever need the editing screen, not these files):
- `content/` all text and settings (edited through the editing screen)
- `static/` images, logos, styles, scripts
- `build.mjs`, `build/` the website generator
- `.pages.yml` layout of the editing screen
- `.github/workflows/deploy.yml` automatic publishing
- `brand-kit/` original logo files for proposals, reports and presentations
- `tools/` link checker and local preview
